# GadgetZone — Smart Gadgets Marketplace

Professional frontend-only gadget marketplace built with React, Redux Toolkit, React Router and Local Storage.

## Features
- 48 products across 10 categories
- Product search, category, price and rating filters
- Sorting
- Product details
- Cart with quantity controls
- Wishlist
- Register / Login / Logout
- Local Storage persistence
- Checkout and dynamic order number
- Responsive professional design
- No `index.css`
- No backend / database / Firebase

## Run
1. Open this folder in VS Code.
2. Run `npm install`
3. Run `npm run dev`
4. Open the Vite URL shown in the terminal.

## Note about images
The project uses remote Unsplash image URLs so the ZIP stays lightweight while still providing many high-quality product images. An internet connection is required to display those images.
